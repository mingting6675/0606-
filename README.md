# 小萤的毕业物语 · 城市生存

一款**单文件 HTML 融合游戏**：把「城市生存沙盒」与「视觉小说」融合，讲述视障青年小萤在陌生城市里经历 **28 天（四章）生存、求职与成长**的毕业物语。

## 运行方式

直接用浏览器（Chrome / Edge / Firefox）打开 `小萤的毕业物语·城市生存.html` 即可，**无需安装任何依赖、无需联网**。

## 项目文件

| 文件 | 说明 |
|---|---|
| `小萤的毕业物语·城市生存.html` | 游戏本体（单文件，零依赖） |
| `小萤的毕业物语·演示页.html` | 汇报演示网页（12 页，含 3 段真实场景音效） |
| `游戏汇报模板.md` | 11 页 PPT 汇报模板 |
| `汇报PPT大纲.md` | 逐页可操作的 PPT 大纲 |

## 技术栈

- 原生 HTML + CSS + JavaScript（ES6+），无任何框架
- 存档保存在浏览器 `localStorage`（键名 `vision_sim_v3`）

## 修改建议

- 所有游戏数据（事件、成就、结局、羁绊、天气、交通、活动等）都集中在单个 HTML 文件的 `<script>` 标签内，从上到下大致分为：数据定义区 → 剧情主线 → 游戏引擎。
- 改完保存后，**刷新浏览器**即可看到效果（若存档缓存了旧数据，清一下 localStorage 即可）。
